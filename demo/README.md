# 마냉이 데모 (HTML · CSS · JavaScript)

빌드나 설치 없이 현재 MVP(UI 단계)를 열어 볼 수 있는 단일 폴더 버전입니다.

## 열기

`index.html`을 더블클릭하면 됩니다. 서버가 필요 없습니다. 글꼴(Pretendard)만 CDN에서 받아 오므로, 오프라인이면 시스템 글꼴로 보입니다.

원하면 이 폴더에서 `python3 -m http.server 8000` 후 http://localhost:8000 으로 열어도 됩니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 모바일 프레임(최대 430px)과 스크립트 연결 |
| `style.css` | 디자인 토큰(`design/tokens.md`)과 화면별 스타일 |
| `data.js` | 고정 샘플 데이터 (`app/src/data/mock.ts`와 같은 값) |
| `app.js` | 해시 라우터(`#/경로`), 화면 15개, 팝업·토스트·필터 등 동작 |
| `assets/` | 로고, SNS 아이콘, 음식 사진 |

## 범위

`app/`(Vite 앱)의 현재 상태와 같습니다.

- 모든 화면이 고정 데이터를 읽습니다. 식재료 추가, 가입, 로그인은 입력과 화면 이동만 되고 저장하지 않습니다.
- 필터, 찜 하트, 알림 스위치, 공지 펼치기는 화면 안에서만 바뀌며 새로고침하면 처음으로 돌아갑니다.
- 범위 밖 기능(가격 비교, 장바구니, 냉장고 연동, 취향 설정, 커뮤니티 등)은 버튼은 그대로 두고 "곧 지원 예정이에요" 안내만 띄웁니다.
- 홈의 "냉장고 연동하기" 팝업은 브라우저 탭당 한 번만 뜹니다.

기준 소스는 `app/`이며, 이 폴더는 시연용 사본입니다. 화면을 바꾸면 양쪽을 함께 고쳐야 합니다.
