# 디자인 토큰 (T0-03)

`design/screen-*.png`(100dpi)에서 픽셀 색을 직접 뽑은 값입니다. 안티앨리어싱 때문에 ±2 정도 오차가 있고, 구현 시 아래 값으로 통일합니다. 코드에서는 Tailwind 테마(`tailwind.config`)의 색 이름으로 한 곳에만 정의합니다.

## 색

| 토큰 | 값 | 쓰임 (근거 화면) |
|---|---|---|
| `primary` | `#0C7B75` | 주 버튼, 활성 탭 칩, 스위치 켜짐, 냉장 막대, 강조 글자 (1, 2, 8, 22) |
| `primary-dark` | `#085F59` | 큰 숫자, 요약 강조 글자 (8) |
| `primary-mid` | `#5EB7B1` | 냉동 막대 (8) |
| `primary-light` | `#BEE2E0` | 실온 막대 (8) |
| `primary-tint` | `#E2F2F1` | 아이콘 타일, 요약 카드, 여유 있음 배지, 보조 버튼(인증 확인), 레시피 이미지 자리 (7, 8, 12) |
| `primary-faint` | `#F0F9F8` | 최저가 카드, 사진 등록 영역 배경 (11, 15) |
| `danger` | `#C20039` | 임박 숫자 배지(솔리드), D-day 임박 글자 (7, 9). 텍스트는 `#C63763` 계열로 보임 |

| `bg` | `#FFFFFF` | 화면 배경 |

색 규칙 요약
- **긴급/임박은 빨강**(D-1~D-3, 임박 배지 · 임박 영역), **여유는 teal 연한색**(D-4 이상). 기준은 3일 이내입니다.
- **부족·주의는 주황**(재료 부족), 충분은 teal 연한색.
- 팝업은 뒤 화면을 어둡게 하고 하단에 취소(회색 글자) / 확인(teal 글자) 두 칸으로 나눕니다.

## 구성 요소 규칙

| 요소 | 규칙 |
|---|---|
| 주 버튼 | `primary` 배경, 흰 글자 굵게, 높이 약 58px, 완전 둥근 모서리(pill), 하단 고정 시 좌우 여백 약 25px |
| 보조 버튼 | `primary-tint` 배경 + `primary` 글자 (인증번호 확인), 또는 흰 배경 + `primary` 테두리 (앨범에서 선택하기) |
| 필터/선택 칩 | 선택: `primary` 배경 + 흰 글자 / 미선택: 흰 배경 + `border` 테두리 + `ink` 글자. 모양은 pill |
| 상태 배지 | 작은 pill. 임박 `danger-tint`+`danger`, 여유 `primary-tint`+`primary-dark`, 부족 `warn-tint`+`warn-text` |
| 카드 | 흰 배경, `border` 1px, 모서리 약 16px |
| 입력창 | 높이 약 56px, 모서리 약 12px, `border` 1px, 라벨은 위에 `ink` 14px |
| 상단바 | 좌상단 "<", 제목 굵게(약 22px). 탭 최상위 화면은 "<" 없이 제목만 |
| 하단 탭 | 5개(홈·냉장고·추천·장보기·마이페이지), 높이 약 78px, 아이콘 + 라벨, 활성은 `primary` + 굵게 |
| 아이콘 | 선 아이콘(stroke), 두께 균일. 식재료는 이름 첫 글자를 `primary-tint` 둥근 사각 타일에 표시(대·두·우…) |
| 스위치 | 켜짐 `primary`, 꺼짐 `switch-off`, 흰 원 |
| 모서리 | 칩·버튼 pill, 카드 16px, 입력창 12px, 타일 12~16px |

## 글꼴

- 이 PDF는 이미지에 글자 레이어가 없어 글꼴 이름을 읽을 수 없습니다. 화면의 산세리프 한글 모양은 **Pretendard**와 가장 비슷합니다.
- 제안: `Pretendard`(없으면 `Noto Sans KR`, `system-ui` 순). 오픈 이슈로 남기고 시안 대조 때 확인합니다.
- 크기(시안 폭 408px 기준): 화면 제목 22~24px 굵게, 섹션 제목 18~20px 굵게, 본문 15~16px, 보조 12~13px, 탭 라벨 11px.

## 로고·이미지

- 로고(마냉이 캐릭터 + 글자)는 시안 화면 1에만 있습니다. 로고 이미지는 `design/screen-01.png`에서 잘라 쓰거나 원본 에셋을 받아야 합니다. 갈색 글자 색은 약 `#704422`.
- 레시피 사진: 홈의 오늘의 추천(참치마요 덮밥, 두부김치)에만 실제 사진이 있고, 추천·찜·상세 화면은 `primary-tint` 바탕에 국그릇 아이콘이 들어갑니다.
